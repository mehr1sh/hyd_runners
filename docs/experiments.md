# Experimental running experiences

Each experiment is either working on real data or explicitly assessed.

| #        | Experience                                   | Status                                        | How                                                                                                                                                                                                                                                                                                             |
| -------- | -------------------------------------------- | --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| M1       | Ghost Runner                                 | **Implemented**                               | On your activity page, your latest earlier run on the _same matched route_ (start, finish and shape match, from Release 2's route matching) is compared kilometre by kilometre using both runs' recorded splits. You see ahead or behind at each kilometre and at the end. Unmatched routes are never compared. |
| M2       | Virtual Pacemaker                            | **Implemented** (mobile, untested on devices) | The app's pace targets, interval transitions and spoken split cues ([mobile.md](mobile.md)), plus the web pace calculator. GPS pace is labelled approximate.                                                                                                                                                    |
| M3       | Run Roulette                                 | **Implemented**                               | `/routes/roulette` picks at random from **verified, published** routes matching distance, difficulty and area. Real routes only, never generated geometry.                                                                                                                                                      |
| M4       | Mystery Run                                  | **Implemented**                               | Organisers attach a published route that stays hidden until a reveal time (`set_mystery_run`, audited). The hidden column can't be selected directly. Before the reveal, runners see the distance; the meeting point, organisers and safety details stay visible.                                               |
| M5       | Coffee Run Finder                            | **Not implemented**                           | Needs licensed business data (names, locations, opening hours). OpenStreetMap is ODbL and could work with attribution, but there's no production geocoding or POI service with appropriate terms, and business data would not be invented. Needs a provider decision.                                           |
| M6       | Run & Explore                                | **Partly**                                    | Neighbourhood routes come from route search by area and place (Release 2 G), with a verified filter. Landmark data has the same licensing gap as M5.                                                                                                                                                            |
| M7       | Run Streak Battles                           | **Implemented**                               | Squad consistency rankings and on-target streaks (E), and consistency leagues (G).                                                                                                                                                                                                                              |
| M8       | Virtual Relay                                | **Implemented**                               | Squad captains start a relay along a preset journey (for example Hyderabad to Bengaluru, 575 km). Members' real distances since the start date move the squad along it, with checkpoints. It's labelled _simulated_, and distances are approximate road distances.                                              |
| M9       | Route Collectibles                           | **Implemented**                               | `/routes/collection`: completions are **computed** from your own GPS tracks matching a published route (within about 150 m in shape, distance within 15%). They're never stored, so they can't be duplicated or claimed without a run. Grouped by area as "x of y".                                             |
| M10, M14 | Community Impact Runs, Challenges for Causes | **Implemented**                               | Challenge organisers attach a campaign (name and https link). It shows as _not yet verified_ until an admin verifies it (audited). HYD Runners handles no donations, and the page says so; no figures for money raised or impact are shown.                                                                     |
| M11      | Run Captains Network                         | **Implemented**                               | `/captains` lists runners who captain or sweep published group runs, with runs led and upcoming. "Verified" appears only for admin-verified run-captain profiles (D).                                                                                                                                           |
| M12      | Beginner Welcome Runs                        | **Implemented**                               | Beginner-friendly series with no-drop and regroup policies (Release 1 C). Run Radar has a "Beginner welcome runs only" filter.                                                                                                                                                                                  |
| M13      | Run Audio Rooms                              | **Not implemented**                           | Voice rooms need paid real-time infrastructure (WebRTC SFU or a hosted voice service) and moderation; not activated without approval. Group announcements already use event updates and club announcements.                                                                                                     |
| M15      | Route Time Machine                           | **Implemented**                               | The same-route history table (Release 2 B) and Ghost Runner compare efforts on the same route over time. No historical weather is stored, so no past conditions are claimed.                                                                                                                                    |
| M16      | Club Membership Pass                         | **Implemented**                               | `/clubs/pass`: every club membership with role or status, member since, club runs attended and booked, and upcoming club runs.                                                                                                                                                                                  |
