# Community — runner-facing parts (`feat/runner-experience`)

Event listings with RSVP/cancel and capacity (`event_rsvps`), the Hyderabad map explorer with a list alternative and type filters, the weekly XP leaderboard (`weekly_leaderboard()`) with a privacy toggle, and share buttons. Event _management_ (creating and editing events) stays with the management area; this folder only reads `events` and `locations`. Unverified/sample places and events are labelled.
